Favicon set made from the master mark, in `bc-steel-blue` (#4682B4), which reads on both light and dark browser tabs (4.76:1 on near-black, 4.11:1 on white; icons need 3:1). `favicon.svg` is the scalable icon; `favicon-16.png`, `favicon-32.png` and `favicon-48.png` are transparent PNG fallbacks; `apple-touch-icon.png` (180px), `icon-192.png` and `icon-512.png` sit on the near-black `bc-surface` ground with padding, because home-screen icons must be opaque. Link them from every page head: `<link rel="icon" href="/favicon.svg" type="image/svg+xml">`, `<link rel="icon" href="/favicon-32.png" sizes="32x32" type="image/png">`, `<link rel="apple-touch-icon" href="/apple-touch-icon.png">`, and list `icon-192.png` and `icon-512.png` in the web app manifest. At 16px the mark's thin strokes soften; use the 32px file at 2x where you can. No `.ico` file is included.
