Corner line patterns from the Block Concepts letterhead: diagonal hairlines that run dashed on one side and solid on the other. The dashed lines are concept and the solid lines are build, so the pattern shows an idea becoming a delivered system. Both are transparent PNGs in the dark `bc-wordmark-gray` value (#9AA3AC), cut from the page art so they sit on the dark website; set them at 50 percent opacity. `lines-top-right.png` is the main graphic: place it in the top right corner of a hero or page with the dashed lines on the inner side and the solid lines running off the corner. `lines-bottom-left.png` is the secondary corner for the bottom left. One pattern per view, anchored to a corner, never behind running text.
