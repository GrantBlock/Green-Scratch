# Session V2: Projects, documents and schedule

Address: `vault.blockconceptsllc.com`. Phone and iPad matter most here.

Design:
1. **Projects list:** stage (Design, Build, Install, Closed), account, completeness bar.
2. **Project record** with sub-tabs: Overview (account, value, dates, stage, Onshape and OneDrive links), Documents, Schedule, Sourcing, Money, Jobs, Updates, Share.
3. **Documents:** the folder structure in `docs/FOLDER-STRUCTURE.md` with a checklist per folder (Missing, Requested, Received, In review, Released); file list with revision and status; upload; Request from customer; completeness bar.
4. **Schedule (Gantt):** schedule items with a Category dropdown, dependencies, percent complete, a baseline overlay with a baseline picker, a today line, a reason prompt when a date moves, per-item updates; zoom week and month; touch drag and resize with an edit-form fallback. This is the riskiest screen; design the touch behavior with care.
5. **Sourcing:** item, supplier, quote requested, quoted, ordered, received.
6. **Share:** create an expiring link, choose which released documents are shared, see last use, revoke.

Data: Project, Checklist item, Job, Schedule item and Baseline, Sourcing item, Document, Share link.
