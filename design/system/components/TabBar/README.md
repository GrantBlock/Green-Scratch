Horizontal tab bar for a fixed set of sections, one row, no wrapping or scrolling. Provide `tabs` as `{id, label}`, `value` or `defaultValue`, `onChange(id)`, `label` (the tablist's accessible name) and optionally `panelId`. Tabs share the width equally and the type scales from 14px down to 9px to fit; use six or fewer tabs with labels of one or two words. It is an ARIA tablist: Arrow keys move and select, Home and End jump, and only the active tab is in the tab order. The active tab has a Steel Blue underline and bold label.
