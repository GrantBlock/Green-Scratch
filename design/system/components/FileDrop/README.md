File input with a dashed drag area and a Choose file button. Provide `label`, `accept` (such as `.pdf`), `onFiles(FileList)`, and optionally `fileName`, `hint`, `error`, `disabled`. The button is the keyboard path; dropping a file is a convenience. After a file is chosen the area shows its name and the button reads Replace file. State size and type limits in `hint` and report a rejected file in `error`.
