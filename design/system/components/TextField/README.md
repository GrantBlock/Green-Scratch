Single-line text, email and number input with a visible label, hint, error and optional unit suffix. Provide `label`, and optionally `type` (`text`, `email`, `number`), `value` or `defaultValue`, `onChange(value)`, `hint`, `error`, `suffix` (a unit such as in or psi), `optional`, `disabled`. Labels are always visible; never use a placeholder as the label. Only `type="email"` validates, on blur, and shows "Enter an email address like name@company.com"; all other fields accept any text, and you pass `error` yourself for server-side problems. Inputs are 16px so phones do not zoom, 44px tall, with a 2px `bc-steel-blue-text` focus outline.
