Vertical single-select list that scrolls on its own. Provide `items` as `{id, label, meta}`, `value` or `defaultValue`, `onChange(id)`, `label` (accessible name), `height`, and `search` to add a labelled search box above it. The active row is a solid Steel Blue with a white semibold label. Arrow Up and Down, Home and End move the selection; rows are at least 44px. Use for the Grab this columns.
